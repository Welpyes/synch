# Synch

A fetch program written in Lua for Luajit inspired by [Synfetch](https://github.com/SXSLVT/synfetch) and [Nitch](https://github.com/ssleert/nitch)

## Why Lua?

Lua is a versitile program and very easily extended and customized and with Luajit, it makes the progtam very fast and competes in speed with compiled language in the likes of go and c
